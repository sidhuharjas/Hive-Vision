# Collecting training data

Repo:
[README workflow](https://github.com/sidhuharjas/Hive-Vision/blob/main/README.md).
In one screen:

1. Share the original footage (video or stills) in the [Discord](https://discord.gg/m2yPTprccv)
   or a GitHub issue.
2. Include: source, camera, resolution, frame rate, lighting, field location,
   permission to redistribute.
3. Split empty-field footage from visible-ball clips.
4. Label balls only as `yellow`/`red`/`blue`; never label lookalikes.
5. Note hard cases the current model missed.

Accepted data lands in roughly the next biweekly model revision.
